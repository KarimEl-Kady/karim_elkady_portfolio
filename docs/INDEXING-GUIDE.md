# Indexing and measurement guide

The canonical homepage is `https://karimel-kady.online/`; submit `https://karimel-kady.online/sitemap.xml` after the changes are deployed and the URL responds successfully. None of the following account actions has been performed.

1. In Google Search Console add a Domain property for `karimel-kady.online`, copy the TXT value Google supplies into the domain's DNS, and complete verification. In Bing Webmaster Tools add the site and follow its current DNS or other ownership verification instructions. Never commit verification secrets or invented tokens.
2. Submit the sitemap in each service. Check the sitemap report for fetch and parsing errors. Inspect the canonical homepage using URL Inspection and run the live test; request indexing only after it passes. A request is not a guarantee of indexing.
3. Check page indexing, crawl statistics, sitemap errors and manual actions periodically. Confirm the canonical selected by Google, and investigate redirects, 404s, blocked resources and unexpected noindex. Use Search Console Performance for organic queries, pages, impressions and clicks; compare similar date ranges and annotate releases.
4. Verify with actual HTTP requests that `/`, `/robots.txt`, and `/sitemap.xml` return 200, missing URLs return 404, and sitemap URLs resolve to their own canonical. Check HTTP and HTTPS plus www/non-www redirect chains and TLS using the hosting provider's settings. Ensure the preferred host and sitemap agree. Static HTML cannot enforce host redirects or response headers.
5. Inspect the deployed robots file and CDN/WAF logs and rules for Googlebot, Bingbot and OAI-SearchBot. Robots allows `*` in this repository, but a real request and provider logs are needed to assess reachability and legitimate crawler identity. Do not conflate OAI-SearchBot (search) with GPTBot (training), or change training policy without an explicit decision. Consult each provider's current crawler documentation; directives and verification methods vary.
6. If analytics is explicitly authorized, create a GA4 property and install its real measurement ID under an appropriate privacy/consent policy. Without analytics, do not infer visits from search impressions. GA4 traffic acquisition and server logs can show identifiable referrals such as `chatgpt.com`, `perplexity.ai`, or `copilot.microsoft.com`; attribution can be absent or stripped, so these counts are incomplete. Group sources only after inspecting actual referrers and avoid interpreting direct traffic as AI traffic.
7. Record periodic manual searches for the name and specific repository topics across accessible AI search products, noting date, query, region, citation URL and whether the answer was correct. Results vary by account and time; a sampled citation is not a ranking or comprehensive measure.
8. IndexNow is optional and requires a supported host/key and a submission process. The existing sitemap is sufficient preparation; do not create a key or submit URLs without setting up and verifying the integration.

When a new public page is added, give it unique source-rendered metadata and an absolute canonical, link it from the site, add its canonical URL to `sitemap.xml`, and run `python3 tests/validate.py` after updating the sitemap expectations. Do not include private, redirected, noindex or error URLs.
