# SEO validation

Run `python3 tests/validate.py` and `git diff --check` from the repository root. On 2026-11-13 both passed. The dependency-free test checks source HTML metadata uniqueness, absolute canonical, JSON-LD syntax, fragment links, local assets, image alt attributes where images exist, the current one-URL sitemap, robots sitemap declaration and the 404 noindex directive. Update its explicit sitemap expectation as public pages are added. It does not validate schema semantics, HTTP status, external links, computed accessibility, or rendering.

This is a static site with no build step. Source homepage size: baseline 43,729 bytes, after change 46,135 bytes; this is not a network or user-experience performance measurement.
